# 戴尔生日住宅

## Description

1939 年家庭生日场景，也是戴尔最深创伤被蓝方块反复进入的记忆空间。

## Story Function

- 让戴尔从可靠侦探变成第二名受害者；
- 把兔面人物从旅馆历史带到现代刑事创伤；
- 证明过去的记录可以出现结果变化；
- 为“档案不是伪造，而是记忆版本”提供决定性先例。
