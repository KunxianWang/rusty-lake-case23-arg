# 范德布姆家宅

## Description

族谱、肖像、器官记录、种子、钟表和树根在这里构成跨代复生图景。网站通过户籍与私人材料呈现，
不让档案维护者直接解释完整仪式。

## Story Function

- 确认威廉与阿尔道斯的灵药交换；
- 重建威廉等待转生的家族过程；
- 在中点确认劳拉是威廉的新生命；
- 使乌鸦先生与劳拉之间的关系从“实验者／对象”扩展为兄弟轮回的伦理悖论。
