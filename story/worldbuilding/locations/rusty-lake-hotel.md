# 锈湖旅馆

## Description

1893 年的旅馆记录以登记、菜单、房间和动物肖像出现。其日常服务外观掩盖了对客人记忆的收集。

## Story Function

- 把动物客人与天堂岛埃兰德家族并置；
- 让哈维从劳拉的生活细节变成跨年代行动者；
- 把兔子先生链连接到戴尔的生日创伤；
- 展示猫头鹰先生对黑色记忆的早期系统性收集。

## Boundary

配对可以达到“高度相关”，但跨作品身份仍依原作开放程度标注证据等级。
