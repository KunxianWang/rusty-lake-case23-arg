# 白门

## Description

以规律日程、创伤治疗和恢复正常生活为表面语言的机构。内部表格把人的记忆拆成可记录、可处理的项目。

## Story Function

- 把鲍勃从嫌疑人重新解释为创伤幸存者；
- 让记忆技术获得人类代价，而不只是一套炼金机制；
- 暗示锈湖式记忆处理在现代机构中的延伸。

## Boundary

本作不额外宣布白门与所有锈湖场所具有可验证的现代法人隶属关系，只通过方法、符号和材料形成联系。
