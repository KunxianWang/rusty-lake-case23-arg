# 劳拉住所

## Description

23 号案的现实入口：日常家具、画作、电话、窗、门、哈维与劳拉的身体共同构成现场。

## Story Rules

- 三版现场照片必须共享足够多的固定参照，使差异可被公平观察；
- 遗体从封闭现场消失，不补写常规运输过程；
- 超自然细节前期只存在于被划去的补充报告和图像边缘；
- 私人物件优先展现劳拉的人格，不用来集中解释世界观。

## Current State

玩家只能访问扫描记录，不进入现场，也不改变 1971 年事件。
