# 天堂岛

## Description

1796 年埃兰德家族、十场灾祸、卡罗琳研究与雅各布牺牲的所在地。

## Story Function

天堂岛提供猫头鹰先生的来源和动物面具的家族语境。其材料必须在玩家已经理解范德布姆轮回之后出现，
否则会造成过早的名词堆积。

## Reveal Principle

先让玩家通过家族照、面具和旅馆登记完成可观察配对，再提供雅各布／卡罗琳关系；
不由项目注释直接写出完整神话史。
