# 锈湖磨坊

## Description

表面是老旧磨坊，维修图却显示电视、时钟、固定架、动力装置和记忆储存槽属于同一系统。

## Story Function

磨坊是全篇第一次明确打破现实物流的地点。劳拉在 1971 年现场消失，1972 年通过电视与时钟相关过程
出现在此处。玩家能证明两地相连，却找不到车辆、船只或人员交接。

## Notable Features

- `A. Vanderboom` 房产记录；
- 1972 年异常高负荷；
- 电视静帧和时钟校准；
- 白、黑记忆提取装置；
- 鸟首人物照片。
