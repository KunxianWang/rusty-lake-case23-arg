# 锈湖洞穴

## Description

三条主线的汇合点：劳拉的记忆、戴尔的测试和猫头鹰／乌鸦的锈湖系统在机器中连接。

## Notable Features

- 戴尔与劳拉位于设备两端；
- 白、黑、蓝方块参与过程；
- 第四个空位最终对应金方块；
- 电梯与路线图指向戴尔后续旅程。

## Story Function

洞穴不再引入新的家族百科，而负责把已知关系组合成最终答案。
