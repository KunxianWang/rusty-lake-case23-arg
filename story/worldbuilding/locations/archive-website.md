# 锈湖地方档案网站

## Description

2003 年建立、2008 年停更的静态地方史网站。米白背景、深蓝链接、灰色表格和低清湖景构成外观；
导航、搜索、进度和缩放必须保持现代可用性。

## History

图书馆搬迁前发现一批水损、来源混乱的材料。米里亚姆负责来源和说明，丹尼尔负责扫描、OCR、
静态页面与备份。随着冲突版本无法验证，网站最终转为只读。

## Notable Features

- 本周档案与大量无关地方新闻；
- 站内关键词搜索；
- 每份材料的来源、录入者和可信度；
- 历史版本并排比较；
- 已发现档案列表；
- 2008 年停更公告。

## Current State

玩家访问最后一次公开备份。页面变化代表已经存在的档案关联被玩家发现，不代表网站在监视玩家。
