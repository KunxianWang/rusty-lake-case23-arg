# Worldbuilding

## World Overview

本作不新建一套凌驾于原作之上的宇宙规则。外层世界是普通地方档案系统，内层世界沿用锈湖中
“记忆可被提取、储存、重历和改变”的机制。玩家只能通过不完整材料推断两者的交界。
