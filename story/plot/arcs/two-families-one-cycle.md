# 两个家族，同一个循环

## Setup

玩家先把 23 号案理解为劳拉个人遭遇，与更早家族史无关。

## Rising Action

1. 威廉死亡、阿尔道斯长生，范德布姆家族完成威廉转生。
2. 雅各布与卡罗琳的牺牲形成猫头鹰先生，埃兰德成员与旅馆动物客人高度对应。
3. 哈维在两个家族、多个年代之间反复出现。
4. 戴尔的生日创伤与劳拉的死亡记忆被纳入同一套测试和提取系统。

## Climax

洞穴设备把劳拉和戴尔放在两端，以白、黑、蓝记忆形成金方块。

## Resolution

两个家族不是由本作新造的幕后黑手统一，而是通过锈湖已有的记忆循环、猫头鹰先生和乌鸦先生相交。
戴尔的继承可能性保持为强烈暗示。
