# 档案项目停止维护

## Setup

米里亚姆相信每份文件都可以追溯到原件，丹尼尔相信每次文件变化都可以追溯到技术操作。

## Rising Action

1. 两人先用水损、OCR、色偏和覆盖解释异常。
2. 米里亚姆发现同一档案拥有无法排序的来源链。
3. 丹尼尔发现冲突文件没有上传或篡改日志，恢复同一备份还会产生不同版本。
4. 米里亚姆撤下证据等级过高的推断，拒绝把猜测写成事实。

## Climax

两人共同承认：现有方法无法证明冲突文件中哪一份是复制件，也无法证明“原件”只有一个。

## Resolution

网站于 2008 年转为只读。两人仍是普通档案工作者，没有被选中、失踪或掌握锈湖全史。
