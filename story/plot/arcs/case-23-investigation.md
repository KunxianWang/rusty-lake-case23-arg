# 23 号案调查

## Setup

玩家进入停更网站，把 23 号案当成一宗前男友可能涉案的普通女性死亡案，并试图找回缺失附件
`23-BLACK`。

## Rising Action

1. 鲍勃嫌疑缺乏证据，劳拉遗体从封闭现场消失。
2. 1972 年磨坊材料出现劳拉，白、黑记忆被提取。
3. 白门把鲍勃从嫌疑人改写为创伤幸存者。
4. 范德布姆族谱确认劳拉是威廉的转世。
5. 戴尔童年案、旅馆与天堂岛揭示第二条家族循环。
6. 洞穴机器把劳拉与戴尔的记忆汇合。

## Climax

玩家打开 `23-BLACK`，拒绝在互不兼容的记忆版本中强选一个“真正死因”，转而完成六项人物、
地点与机制关系报告。

## Resolution

案件状态变为“不适用线性因果”。玩家能够解释矛盾为何存在，却不被允许用本作虚构的唯一凶手
覆盖原作的开放性。
