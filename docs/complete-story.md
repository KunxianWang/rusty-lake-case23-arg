# 《锈湖档案：23号案》完整剧情圣经 V2

> 非官方、非商业《Rusty Lake / Cube Escape》同人 ARG。  
> 本文定义首部游戏的完整故事、揭露顺序、人物功能、情绪线与结局。玩法和页面规格仍以
> [V1 大纲](rusty-lake-case23-outline.md)为基础；结构化人物、悬念和伏笔记录见
> [`story/`](../story/story.md)。

## 1. 故事承诺

玩家访问一个于 2008 年停止维护的地方档案网站，原本只想弄清 1971 年劳拉·范德布姆死亡案，
却发现同一案件的照片、时间与尸检记录无法构成唯一版本。调查从一间公寓延伸到锈湖磨坊、
白门、范德布姆家族、天堂岛、锈湖旅馆和洞穴，最终迫使玩家放弃“找出唯一凶手”的传统框架：

> 档案保存发生过的事；记忆保存被发生过的事改变的人。  
> 当记忆可以被提取、重演和改写时，一宗死亡案可以拥有彼此冲突、却同时有效的版本。

这不是“玩家被锈湖选中”的故事。玩家只是一名匿名访问者，完成别人没能完成的关系整理。
页面不会叫出玩家的名字，不会声称正在监视玩家，也不会让玩家改变劳拉或戴尔的命运。

## 2. 四条不可动摇的创作边界

1. **劳拉首先是一个人，其次才是转世与记忆载体。** 她必须拥有画作、感情、恐惧和想要离开的愿望，
   不能只作为开启世界观的钥匙。
2. **劳拉之死没有一个由本作擅自指定的唯一凶手。** 自杀推测、腐化灵魂、戴尔的记忆重演、
   记忆提取和《Paradox》中的不同结果会被并置，但不被压成一条伪造的确定答案。
3. **档案项目成员是普通人。** 他们会误判、犹豫和停工，但不会突然掌握锈湖全史，也不会集体失踪。
4. **同人材料只负责连接，不负责改写正史结果。** 每个重要结论都标记为“原作明确”“强烈暗示”
   或“本作补充”。

## 3. 真相分层

| 层级 | 玩家最终能确定的内容 | 边界 |
|---|---|---|
| 原作明确 | 威廉死亡后等待转生；阿尔道斯成为乌鸦先生；劳拉是威廉的新生命；劳拉的身体在磨坊被用于提取白、黑记忆；戴尔因 23 号案进入锈湖体系 | 不改变结果 |
| 强烈暗示 | 旅馆兔子先生、`D. Eilander` 与生日案兔面凶手属于同一轮回链；猫头鹰先生把戴尔作为潜在继承者测试 | 最终报告使用“可能”“高度相关” |
| 本作补充 | 地方档案数字化计划、两名维护者、档案编号、网页版本冲突、行政记录和谜题顺序 | 不创造新幕后黑手 |
| 有意不定 | 劳拉在传统刑侦意义上的唯一死因；兔子身份在所有年代的一一对应；戴尔最终是否继承锈湖 | 留给原作与续作 |

## 4. 游戏外层：谁建立了这个网站

### 米里亚姆·哈特

2003 年时 64 岁，锈湖县立图书馆退休档案员。她曾在 1981 年地下库房进水后，参与整理一批失去
来源标签的案件资料。她一直认为“来源不清的文件等于没有文件”，因此退休后主动负责数字化计划。

她的项目注释始终谨慎：

- 不写“超自然”，写“无法确认原件”；
- 不写“同一个人活了一个世纪”，写“肖像归属可能有误”；
- 不写“方块改变过去”，写“同一底片存在多个版本”。

她的弧线不是从凡人变成知情者，而是从“每份记录都能回到一个原件”走到“我们无法证明原件只有一个”。
她最终签署停更公告，理由是职业伦理：无法验证来源，就不应继续把推断冒充事实。

### 丹尼尔·摩尔

2003 年时 23 岁，负责扫描、OCR、静态网页和备份的志愿者。他最初把所有异常归因于技术问题：
缓存、文件名覆盖、扫描仪色偏、服务器时钟错误。到 2008 年，他发现同一个文件名在没有任何上传记录的
情况下出现互不相同的图像，而且不同版本都拥有早于网站建立日期的时间戳。

丹尼尔没有被锈湖追杀，也没有破解宇宙真相。他只做出一个可靠的技术结论：

> 数据库里没有一次可追踪的“篡改”；冲突版本看起来都像最初就存在。

他保留最后一次公开备份，关闭写入权限，并在维护日志中留下校验值。玩家访问到的正是这份备份。

### 两人的叙事作用

- 米里亚姆代表“档案是否可信”；
- 丹尼尔代表“文件是否被改动”；
- 玩家代表“这些记录能否被重新理解”。

他们不抢走锈湖角色的主线，只为玩家提供一个可信、有限、逐渐失效的观察框架。

## 5. 完整故事

## 序章：最后一次公开备份

游戏打开在 2008 年的停更首页。页面是普通的地方图书馆旧站：湖景横幅、天气、小镇活动、
访客计数器、扫描志愿者名单和“本周档案”。停更公告解释说，部分资料来源无法核实，
同一文件出现了互不兼容的版本。

“本周档案”仍指向 1971 年的 23 号未结案。案件目录写着“附件六件”，页面只显示五件。
缺失项叫 `23-BLACK`。米里亚姆把 `BLACK` 理解为黑白底片分类，丹尼尔把它理解为损坏文件名。

玩家得到第一个简单目标：找回缺失附件。

此时玩家相信：

> 这是一个维护失败的旧网站，23 号案是一宗可能涉及前男友的普通死亡案。

## 第一幕：记录可信

### 第一章：普通死亡案

劳拉·范德布姆于 1971 年秋被发现死在住所。地方报纸用暧昧措辞暗示感情纠纷，询问记录显示她刚与
罗伯特“鲍勃”·希尔分手。鲍勃情绪失控、证词断裂，很容易成为第一嫌疑人。

但每份材料只支持“他受到打击”，没有证据证明他在案发时进入现场。为了不让劳拉只剩下一具尸体，
页面同时展示她的画、写给鲍勃却未寄出的便笺、与哈维相处的生活照片。她害怕某个反复出现的梦，
也想结束一段让双方都痛苦的关系。

戴尔·范德米尔的办案便笺比新闻克制。他记录门窗、电话、现场物件和时间，却在纸角反复画一个方形。
三份现场图拥有相同档案号，哈维的位置、尸体朝向和窗外光线却不一致。

玩家通过警察印章、报纸日期和附件编号得到检索词 `CASE 23`，打开完整目录。随后把四个时间节点排序：

1. 邻居报警；
2. 戴尔进入住所；
3. 现场被封闭；
4. 尸体确认不在现场。

排序后最重要的不是“哪辆车提前离开”，而是：

> 记录中没有任何尸体交接、运输或停尸房入库。封闭现场里的一具尸体消失了。

一份被裁掉上半页的现场补充报告提到短暂停电、黑色飞蛾和“物体向上移动”。警局副本把这句划掉，
米里亚姆注记为“证人受惊后的不可靠描述”。

### 第一幕转折：没有交接记录

玩家在站内搜索案件号时，得到一个不属于警察目录的结果：1972 年磨坊设备维修包里的一张电视静帧。
画面极差，但图像边缘写着 `23`，屏幕里的人影与劳拉现场照片相同。

玩家的理论从“鲍勃杀了劳拉”变成：

> 有人从封闭现场取走了尸体，并在一年后于锈湖磨坊继续处理她。

这仍然是错误的现实化解释，但足以把玩家带进第二幕。

## 第二幕：记录被篡改

### 第二章：没有运输过程的目的地

磨坊房产记录长期与 `A. Vanderboom` 这个姓名缩写相关。1972 年的电力故障单记录了一次不符合
磨坊生产规模的瞬时高负荷。维修图把电视、时钟、管线、人体固定架和储存槽连成一套设备。

玩家先后找到：

- 一张电视屏幕出现劳拉身体的维修照片；
- 一份钟表校准记录，时间与屏幕图像同步；
- 一页没有任何车辆、船只或人员交接的保管审计；
- 一张鸟首人物站在提取装置旁的损坏照片。

米里亚姆认为鸟首是防护面具，丹尼尔认为电视画面是后期叠片。两人都无法解释为什么 1972 年的纸质
维修照片包含一年前封闭案卷里的图像。

玩家依据电力脉冲、时钟刻度与管线编号重排设备流程：

> 让对象出现 → 接入头部与机器 → 分离两类记忆 → 将结果保存为方块。

白方块对应相对平静、可以重历的记忆；黑方块对应痛苦、恐惧和腐化。被提取之后，劳拉的身体发生腐化，
她的腐化灵魂并没有安静留在磨坊。

### 鲍勃的第二种身份：不是嫌疑人，而是余波

白门材料把鲍勃重新带回主线。劳拉死亡后，他试图结束自己的生命，随后进入白门。机构以治疗创伤为名，
把日常、梦境和劳拉相关记忆拆成可记录、可清除的项目。

玩家第一次意识到，鲍勃早期证词的混乱未必是撒谎，而可能是创伤、腐化与后来记忆处理留下的结果。
他的材料承担全篇最温情也最残酷的部分：

- 他记得劳拉爱画什么，却记不清最后一次对话；
- 他把一只熟悉的鸟错认成普通宠物；
- 他在“恢复正常”的日程里逐渐失去关于劳拉的具体细节。

对玩家而言，记忆方块不再只是炼金道具，而是一个人被留下或被夺走的生活。

### 第三章：死者出生之前

`A. Vanderboom` 把调查带到 1859 年。威廉与阿尔道斯·范德布姆研究生命与死亡灵药：
威廉死亡并成为腐化灵魂，阿尔道斯存活，后来成为乌鸦先生。

玩家在范德布姆族谱中整理詹姆斯之后的家族成员。每一代的出生、死亡、器官、种子、钟表和树根，
起初像病态的家族收藏，完成族谱后却组成一场跨世代的复生仪式。罗斯的材料和“Samsara”档案把
威廉的灵魂引向 1935 年出生的劳拉。

中点反转不是“劳拉像威廉”，而是：

> 劳拉是威廉终于获得的新生命。她在 1971 年的死亡，也是威廉第二次被锈湖收回。

这一答案解释了磨坊为何由阿尔道斯／乌鸦先生操作，也让案件产生伦理重量：参与提取劳拉记忆的人，
同时是她前世的兄弟。

玩家此时可能认为一切都是范德布姆家族内部的轮回计划。下一份材料推翻这个范围：
1893 年锈湖旅馆照片背面提到一名尚未出生的侦探。

### 第四章：另一名受害者

戴尔从调查者变成调查对象。1939 年，他九岁生日当天，家人被兔面闯入者杀害。不同版本的生日材料中，
蓝色方块使这段过去能够被重新进入，甚至出现结果变化。

旅馆登记、动物客人肖像与天堂岛埃兰德家族材料之间形成一组跨年代对应。玩家可以高度怀疑
`D. Eilander`、旅馆兔子先生与生日案兔面凶手属于同一身份链，但网站不会把这种关系伪装成
毫无争议的户籍事实。

天堂岛材料补全另一条家族史：

- 卡罗琳研究记忆与灵药，并曾代替雅各布牺牲；
- 雅各布后来仍被家族献祭；
- 雅各布与卡罗琳留下的力量共同形成猫头鹰先生；
- 旅馆中的五名动物客人与埃兰德家族的轮回强烈相关；
- 哈维奉命处理旅馆客人并收集黑色记忆。

这时玩家才看清两条镜像链：

| 范德布姆链 | 埃兰德链 |
|---|---|
| 威廉死亡，等待复生 | 雅各布死亡，成为管理者 |
| 阿尔道斯存活，成为乌鸦先生 | 卡罗琳的研究成为猫头鹰先生力量的一部分 |
| 劳拉承接威廉的新生命 | 动物客人承接家族的罪与惩罚 |
| 记忆被提取 | 记忆被收集 |

戴尔与劳拉也互为镜像：

- 戴尔调查劳拉的死亡，却被迫重历自己的童年死亡现场；
- 劳拉的记忆被提取，戴尔的记忆被测试和改写；
- 两人都不是单纯的“实验材料”，但锈湖体系把他们当成可以组合的记忆来源。

### 第二幕转折：侦探也是档案

戴尔最后的便笺不是结案推理，而是一张洞穴机器草图。图上有白、黑、蓝三色方块和一个空白位置。
玩家至此会形成新的理论：

> 猫头鹰先生并不是帮助戴尔破案，而是在观察他能否承受、理解并重新组织这些记忆。

这项“潜在继承者测试”是强烈暗示，不是本作替原作宣布的最终任命。

## 第三幕：记录就是记忆

### 第五章：湖需要记忆

洞穴设备把之前分散的页面变成同一套系统：

- 白方块让过去被重新经历；
- 黑方块让人面对创伤、恶魔与腐化；
- 蓝方块使过去可以被重新进入并产生变化；
- 金方块与过去、未来及更完整的记忆形态相关。

戴尔与劳拉被连接在机器两端。乌鸦先生操作设备，已有的白、黑、蓝方块参与形成金方块。
劳拉的案件不再通向“凶手”，而通向“锈湖如何利用记忆维持循环”。

玩家此时找到 `23-BLACK`。它并不是一张遗失的黑白底片，而是一组互不兼容的劳拉死亡版本索引：

1. 警察记录里的原因不明；
2. 鲍勃记忆里的失去与空白；
3. 腐化灵魂介入的死亡图像；
4. 戴尔在《Paradox》式记忆结构中看到的不同结果；
5. 磨坊提取后的腐化与逃离。

附件不给出“真正版本”按钮。它证明缺失文件从一开始就被错误理解了：
`BLACK` 不是胶片颜色，而是与劳拉痛苦记忆相连的黑色分类。

### 最终谜题：关系报告

最后一页沿用地方档案的标准调查表，但把“嫌疑人”栏改成六组关系：

| 问题 | 可接受结论 | 结论等级 |
|---|---|---|
| 劳拉的前世是谁 | 威廉·范德布姆 | 原作明确 |
| 乌鸦先生的前身是谁 | 阿尔道斯·范德布姆 | 原作明确 |
| 猫头鹰先生来自哪条牺牲链 | 雅各布与卡罗琳 | 原作明确 |
| 兔面人物与埃兰德家族是什么关系 | `D. Eilander`／大卫链高度相关，但跨作品身份仍保留余地 | 强烈暗示 |
| 劳拉的身体为何出现在磨坊 | 提取并利用白、黑记忆 | 原作明确 |
| 戴尔为何被引向锈湖 | 被观察、测试，并可能成为继承候选者 | 强烈暗示 |

每项答案都至少由两份已发现材料支持。答错时，系统提示“人物正确但年代不足”或“关系成立，
但证据不能支持唯一身份”，不要求玩家穷举密码。

六项完成后，案件状态从“未结案”变成：

> **不适用线性因果**

这不是说什么都无法知道。玩家已经确定了人物关系、记忆机制和家族循环；无法确定的只是
传统刑侦表格要求的那种单一、线性死因。

## 尾声：停止整理

玩家得到三层并列结论：

| 记录体系 | 最终结论 |
|---|---|
| 1971 年警察记录 | 死因与责任人无法确定，遗体去向缺少现实交接链 |
| 2003—2008 年档案项目 | 多个来源把案件连接到磨坊、白门和更早家族材料，但无法验证唯一原件 |
| 玩家重建 | 劳拉的死亡、腐化、记忆提取与轮回是同一因果网络中的多个记忆状态 |

之后出现米里亚姆与丹尼尔的 2008 年停更记录。他们没有写“锈湖是真的”，只写：

> 我们无法再把较早的时间戳视为较早的版本，也无法证明冲突文件中哪一份是复制件。
> 在来源关系恢复之前，本项目不再发布新的推断。

页面统计显示“已发现 30 个档案”，但索引总数为 31。返回案件目录后，多出一项：

> **CASE 24：Dale Vandermeer — Status Pending**

页面只有建档日期、空白状态和一张未完成的电梯路线图。它不认识玩家，也不要求玩家继续；
它只说明劳拉的案卷结束时，戴尔的案卷才刚开始。

## 6. 三条情绪线

### 劳拉：从“尸体”回到“人”

| 阶段 | 玩家看到的劳拉 |
|---|---|
| 开始 | 报纸标题中的死者 |
| 第一幕 | 会画画、爱哈维、努力结束痛苦关系的年轻女性 |
| 第二幕前半 | 被鲍勃怀念、又从鲍勃记忆中逐渐消失的人 |
| 第二幕中点 | 威廉的转世，但仍拥有独立人生 |
| 第三幕 | 被锈湖处理的记忆主体，而不是一件炼金材料 |

### 鲍勃：从“嫌疑人”到“幸存者”

鲍勃承担悬疑故事中的误导，也承担温情。玩家越接近超自然真相，越应该确信一件非常现实的事：
他确实爱过劳拉，而且失去她之后没有能力理解自己发生了什么。白门把“恢复正常”与“忘记劳拉”
放在一起，让玩家意识到治愈和删除之间的危险距离。

### 戴尔：从“调查者”到“被调查者”

戴尔最初是玩家可以信任的专业视角。随着生日案、蓝方块和洞穴出现，玩家意识到他的笔记也可能来自
被重演、改写过的记忆。这个变化不会削弱他，反而解释为什么他能够走到其他调查者无法到达的位置：
他既懂得整理证据，也亲身承受证据不再稳定。

## 7. 档案项目自身的微型故事

项目日志只占主线约 10% 的篇幅，却必须形成完整弧线：

1. **2003：乐观。** 米里亚姆制定来源规范，丹尼尔搭建网站。
2. **2004：技术解释。** 扫描色偏、OCR 错误和文件名覆盖能够解释大部分异常。
3. **2005：来源冲突。** 同一案件出现不同图像，米里亚姆要求保留全部版本。
4. **2006：校验失败。** 丹尼尔证明冲突不是普通覆盖；同一备份恢复后会产生不同文件。
5. **2007：停止推断。** 米里亚姆撤下几篇把兔面人物写成同一人的文章，因为证据等级不足。
6. **2008：只读封存。** 两人共同关闭更新，保留原始索引和校验日志。

这个微型故事让最终停更不是恐怖片惯用的“维护者失踪”，而是一个负责任的决定：
他们承认自己的方法已不适用于这些材料。

## 12. 结局应该留下什么

玩家离开时应同时拥有四种感受：

1. **案件层面的满足：** 人物、地点、方块和家族关系已经能被完整重建。
2. **死因层面的不安：** 没有一个版本有资格吞掉其他版本。
3. **人物层面的温情：** 劳拉与鲍勃不是设定零件，戴尔也不是天生的“被选者”。
4. **世界层面的余韵：** 23 号案只是入口，`CASE 24` 将调查重心转向戴尔。

最终反转不是“网站在看你”，也不是“档案员早就是猫头鹰的人”。真正的反转是：

> 玩家以为档案在记录不同版本的记忆；最后才明白，这些档案本身就是记忆留下的不同版本。
